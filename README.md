# Ubuntu Bootstrap

> 🚀 Bootstrap a fresh Ubuntu machine into a ready-to-use development environment.

`Ubuntu Bootstrap` 是一个用于 **Ubuntu 新机初始化与开发环境配置** 的自动化脚本。

适用于新安装的 Ubuntu、云服务器和虚拟机等环境。

---

## ✨ Features

- 🐧 Ubuntu 系统初始化
- 📦 安装常用系统工具
- 🐍 安装和配置 Python
- 🔧 安装和配置 pyenv
- 🌱 配置 Git 用户信息
- 🔐 配置 SSH Key
- 🛡️ 配置 UFW 防火墙
- 🕐 设置系统时区
- 🧹 系统基础清理
- ⚡ 一键完成 Ubuntu 初始化

---

## 📋 Requirements

- Ubuntu 22.04+
- `sudo` 权限
- 网络连接

建议在**全新的 Ubuntu 环境**中运行。
